## Карта
- **Движок:** MapTiler (не Mapbox). Причина: у основателя только российская банковская карта, Mapbox требует привязку карты для активации даже бесплатного тарифа; MapTiler даёт бесплатный доступ по email без карты.
- **Стиль:** MapTiler Streets (яркий, живой), не стандартный OpenStreetMap-стиль (слишком жёлтый/пустынный на вид — было явное замечание основателя).
- **3D:** через MapTiler SDK JS (на основе MapLibre GL), рельеф включается через `setTerrain`, доступен как переключаемый режим, не основной вид по умолчанию (тяжелее для слабых устройств).

## Бэкенд
- **Django + Django REST Framework (DRF)** — финальный выбор (заменяет открытый вопрос от Этапа 0, дата: 2026-09-13). Причины:
  - Встроенная админка из коробки — готовая панель для волонтёров/админа (это прямое требование Этапа 1 «Wеб-панель»).
  - Встроенный i18n на три языка (ru/en/tg) — задача «Настроить i18n-инфраструктуру» решается штатным механизмом Django.
  - Встроенная аутентификация и роли пользователей.
  - ORM + миграции — модель данных из раздела 5 PROJECT.md описывается без лишней обвязки.
  - `django.contrib.gis` — родная интеграция с PostGIS для геозапросов.
  - DRF — для API, которое будет потреблять фронтенд (карта, списки мест, маршруты).
  - У основателя уже есть опыт с Python.

## База данных
- PostgreSQL + PostGIS. Причина: нужны геозапросы (ближайшие точки, маршруты).

## Хостинг
- Бюджета на старте нет — выбирать бесплатные тарифы. Финальный выбор конкретного провайдера зафиксировать здесь отдельной записью.

## Монетизация
- Без цели извлечения прибыли. Только: платное продвижение в топе выдачи для бизнесов (отели/рестораны/гиды) + добровольные донаты. Никакой навязчивой рекламы, никакой комиссии с бронирований на старте.

## Модерация
- Первый уровень — список запрещённых слов (ru/en/tg), не ИИ. ИИ-модерация — отложенная задача, добавляется после достижения ~1000 пользователей.

## Бронирование
- MVP — заявки без онлайн-оплаты, подтверждение вручную владельцем места. Онлайн-оплата — будущий этап, не блокирует MVP.

## Языки
- Три языка с самого старта: русский, английский, таджикский — заложить i18n-архитектуру сразу, не хардкодить текст.
